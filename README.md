# أبطال الحروف — عالم الحروف العربية

لعبة تعليمية لتعلّم الحروف العربية الثمانية والعشرين (رياض الأطفال والحلقة الأولى) بطابع عُماني.

تمَّ إنجازُ هذا العملِ بواسطةِ المختبرِ التقنيِّ / مدرسةِ التجهيزِ العلميِّ الخاصّةِ
Created by Technology lab - Altajheez Al Ilmi School - 79395837

## ما الجديد في هذه النسخة
- **لا يوجد تسجيل دخول** للطلاب، ولا تُجمَع أي بيانات عنهم (لا Google Sheet ولا بريد إلكتروني).
- في نهاية كل حرف (بعد المراحل الأربع) يكتب الطالب **اسمه** ويختار ولد/بنت، ثم يضغط
  **«تحميل شهادتي PDF»** فيحصل على شهادة A4 جاهزة للطباعة. الاسم لا يُحفظ على الجهاز.
- علامة ✓ على بطاقة الحرف في الصفحة الرئيسية للحروف المكتملة على **هذا الجهاز** فقط
  (تُمسح من إعدادات الصفحة الرئيسية ← «مسح التقدّم»).
- يعمل الموقع دون إنترنت بعد فتحه مرة واحدة (sw.js).

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية (28 حرفًا) |
| `letters/*.html` | لعبة كل حرف (28 ملفًا) |
| `sw.js` | العمل دون إنترنت |
| `manifest.webmanifest`, `icons/`, `favicon.ico` | التثبيت كتطبيق على الشاشة الذكية أو الجهاز اللوحي |
| `404.html`, `_headers` | صفحة الخطأ وإعدادات الاستضافة |

## الرفع إلى GitHub ثم Render
1. فُكّ ضغط الملف، وارفع **محتوياته** (وليس المجلد نفسه) إلى المستودع `abtal-alhuruf` بحيث يكون `index.html` في الجذر.
2. في Render: افتح الموقع ← **Manual Deploy ← Deploy latest commit**.
3. إعدادات Render: Build Command فارغ أو `echo ok`، و Publish Directory = `.`
